## 已知限制

- 仅扫描 Maven `src/main/java` 与 POM 直接声明的非测试依赖。
- 不执行 Maven、不下载依赖、不解析传递依赖，也不提供完整 Java 类型求解。
- Spring 规则不推导运行时 Bean、继承 stereotype 或任意元注解。
- Diagnostic 由 CLI 稳定输出，未进入 Result Schema `0.1.0`。
- 性能上限只约束当前固定合成样例，真实大型仓库需要后续容量证据。

## 兼容与回滚

交付顺序为 Samples → Scanner PR → Scanner `main` CI → tag/Release → Docs。Result Schema 仍是 `0.1.0`，现有消费者无需迁移。

回滚时先撤销 Docs 的 Closed 状态；如发布资产错误，标记 Release/tag 不可用并整体回滚 Scanner S7；只有样例事实本身错误时才回滚 Samples。禁止只改黄金输出或降低测试断言制造通过。
