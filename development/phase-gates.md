# 八阶段执行关卡

[产品路线图](../product/roadmap.md)是阶段、版本和退出结果的唯一事实来源。本文件规定如何执行，不建立其他阶段编号体系。

## 统一流程

1. 读取工作区和目标仓库的 README、AGENTS、Spec、Design 与 ADR。
2. 检查分支、工作树、现有代码和测试；保留用户修改。
3. 先报告计划、影响范围、风险、依赖、验证和回滚。
4. 按“契约/测试 → 领域 → 适配器 → 入口 → 可观测 → 文档”实现最小切片。
5. 先运行最小相关测试，再运行完整质量检查并保存证据。
6. 达到当前阶段退出关卡后，才能启用下一阶段功能实现。

## 停止条件

- 任务要求跨越未通过的阶段关卡。
- 契约、安全、数据所有权或许可证存在会改变实现的未决事项。
- 需要覆盖用户修改、修改已发布迁移、削弱测试或扩大外部权限。
- 新技术没有对应的真实问题、替代比较或 ADR。
- 个人真实验收的具体绑定/技术或 CI 关卡未通过、模型/价格/上下文依据变化、运行范围变化或前一调用失败；有条件授权不允许绕过这些停止条件。
