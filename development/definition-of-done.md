# Definition of Done

一个 Issue 或阶段只有同时满足适用条件，才能标记 Done。

## 单项工作 Done

- 问题、范围、非目标和验收标准清楚，关联 Issue。
- 需要时已评审 Feature Spec、Technical Design、威胁分析或 ADR。
- 实现只解决本任务，不混入无关重构或用户已有修改。
- 新依赖已说明用途、许可证、维护状态、替代方案和替换成本。
- 缺陷有先失败后通过的复现测试；正常、边界和失败路径按风险覆盖。
- 最小相关检查和仓库完整质量检查实际通过，或受阻项已明确记录且任务未误标 Done。
- API、Schema、迁移、配置、日志、指标、审计和 README 与实现同步。
- 没有密钥、个人数据、真实客户源码、完整源码日志或隐藏推理。
- 兼容、发布和回滚步骤可执行；已发布迁移和 Accepted ADR 未被原地改写。

## 阶段 Done

- 路线图列出的阶段退出关卡全部具有可定位证据。
- 阶段用户旅程能在干净环境按 README 复现并独立演示。
- 版本、变更日志、支持矩阵和已知限制已更新。
- 受影响仓库提交、制品、Schema、样例 digest、命令和退出码进入验收报告。
- 下一阶段依赖的公开契约已经发布；未交付能力仍明确标记为未支持。
- 安全零容忍项为零；没有用临时开关、跳过测试或人工修改数据库制造通过。

## 发布 Done

- CI 全部通过，制品来源可追踪，Deploy 兼容矩阵已更新。
- 数据库空库和上一支持版本升级路径通过；应用回滚不依赖回写迁移。
- Staging/演示环境健康检查、核心 smoke test、监控和回滚演练通过。
- 发布结果、限制和失败事实如实记录。
