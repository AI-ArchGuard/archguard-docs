# ADR-0012：个人自用 DeepSeek 接入与阶段 4 发布范围

- 状态：Accepted；个人凭据入口限制由 [ADR-0013](0013-personal-write-only-credential-management.md) 部分替代；真实外发及收费调用尚未获批准
- 日期：2026-10-02
- 决策者：ArchGuard 项目所有者；所有者已确认个人版范围调整，不授权立即真实调用
- 部分替代：[ADR-0010](0010-agent-trust-boundary-and-model-egress.md)的供应商零保留前置条件、[ADR-0011](0011-deepseek-official-api-egress.md)的账户级书面数据处理审批及阶段退出条件，仅限下述个人自用范围；其他信任边界、协议和技术防护继续适用

## 背景

4A–4G 已在合成/默认关闭模型范围完成，4H 合成 Compose 和旧应用回滚/恢复已验证，但真实适配器、Project 启用和真实验收仍未交付。原账户级零保留或等效约束关卡适合企业/客户数据接入；项目所有者目前只在本地个人使用，持有个人 DeepSeek 官方账户，希望完成真实集成后继续阶段 5。

本决策改变项目发布范围，不宣称供应商满足原关卡。新 ADR 接受个人版开发和验收规则；它不是供应商证明、代用户接受服务合同、运行时开关或真实调用授权。

## 决策驱动因素

- 对外发范围和阶段完成作真实、有限的声明，不以假模型通过冒充真实集成。
- 允许所有者兼任运维角色，避免个人版以企业账户级证明作为唯一进度条件。
- 个人使用不意味着输入无敏感信息，也不免除供应商条款、权限、凭据及费用风险。

## 选择

### 个人版边界与数据处理风险

- 阶段 4 `v0.5.0-agent` 的发布目标调整为个人自用版：所有者控制的本地部署、个人 DeepSeek 官方账户和明确选择的 Project，不作为面向客户、多租户或公网服务的验收。
- 真实阶段验收仅使用合成 Finding、Evidence 和 Markdown/纯文本文档。个人日常使用也只能选择本人有权外发的非敏感材料，并遵守 ADR-0010 最小字段投影；不允许完整源码、客户源码、客户/第三方保密资料、凭据、个人敏感信息或无关 Project 数据。持有个人账户不构成材料可外发的证明。
- 个人模式不要求取得供应商针对该账户的零保留或等效书面承诺；改为所有者在具体运行启用前记录公开资料版本、未核实事项和残余风险接受。未知地区、训练/人工复核、日志/缓存隔离与精确保留期限必须标记为未知，不能自行填成已验证或零保留。
- [官方开放平台协议](https://cdn.deepseek.com/policies/zh-CN/deepseek-open-platform-terms-of-service.html)覆盖个人和企业开发者；[隐私政策](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html)不能被解释为本应用下游数据的账户级处理保证。用户自行核对并确认其账户适用条款，本决策不替其接受合同或确认法律合规。
- [官方磁盘缓存说明](https://api-docs.deepseek.com/guides/kv_cache/)在本决策日仍说明默认启用，闲置后通常数小时至数天清理。`store: false`、无会话、个人账户和未重复提交均不证明零保留；不得承诺固定推理/存储地区、不训练、无人工复核或企业合规。
- 企业/客户数据、公网服务或多人使用不属于个人模式，仍受 ADR-0010/0011 的严格账户级数据处理审批约束；阶段 7 接入此类范围前重新评审，不因个人版关闭而视为已满足。

### 不变的协议、凭据与技术防护

- 首个真实协议仍为 ADR-0011 的受限 Responses HTTPS/JSON，固定 `https://api.deepseek.com/responses` 与 `deepseek-flash`；不通过本决策改成 Chat Completions、换提供方、扩展字段、工具、会话、流式或自动重试。实现前重新核对官方协议和模型映射，不兼容时停止并另立决策。
- 复用 Platform 模型端口和模块化单体；公共 Agent 契约、Scanner Result/Rules Schema `0.1.0` 不因范围调整而变化。
- Secret 只由后端运行时托管、限定访问并具备轮换/撤销步骤，不进入前端、Git、Issue/PR、业务表或日志。保留固定 HTTPS 目标、证书验证、最小出站限制、禁止继承代理和正文日志；本 ADR 不表示这些真实出口措施已经实现。
- 部署开关及 Project Maintainer 开关默认关闭，并同时校验启用记录有效性与 Project 授权。Web 构建时展示开关不是授权，既有页面或直接 API 请求不能绕过后台关卡。
- 所有者可以兼任运维和 Maintainer，但批准记录仍须区分数据/风险确认、运维检查、Project 启用及具体验收批次授权。缺失、过期、范围变化或撤销时在创建请求和实际外发前失败关闭。
- 保留三次授权、提示注入隔离、严格 Schema/业务/引用校验、不可变版本、幂等、一次尝试、30 秒硬超时、失败回退和无正文审计；Agent 不改变确定性 Finding、基线、质量门禁或 CI `0/2/64/70`。
- 保留单请求最多 8,000 输入/1,500 输出 Token、0.10 美元，Project 每 UTC 日 5 美元和部署每 UTC 日 20 美元上限。真实价格使用有有效期的版本化美元目录、高峰且输入全未命中的估价，事务预留并按实际用量结算；固定假模型费用不是供应商账单证据。

### 启用记录与单独真实调用授权

启用记录只保存批准人/日期、非敏感账户引用、部署/Project、`PERSONAL` 范围、资料 URL/版本/查询日期、未知事项及风险接受、模型别名/映射、价格目录版本/有效期、Secret 托管与网络检查编号、允许的数据范围及撤销/失效条件。不贴真实账户标识、联系方式、密钥或保密原件；机器可执行表示由 Platform Technical Design 定义，不在 Docs 复制 API Schema。

本次所有者确认只批准范围调整。首次真实验收还须在运行前由所有者单独确认固定官方目标、合成数据批次/用途、请求次数及总费用上限；额度上限不是花费授权。解释和摘要各自仍只在显式用户操作下创建请求。未获得该授权、未配置有效 Secret/记录或技术校验未通过时，真实调用继续关闭。

### 实施、发布与阶段退出

1. 本 ADR、Feature Spec 和路线调整经 Docs PR 合并且 `main` CI 成功后，才启动 #43 的真实适配器和默认关闭的 Project/部署启用实现；CI 及本地开发继续使用假模型/假 HTTP，不发送真实请求。
2. 按 Docs → Samples/Platform → Web → Deploy 顺序合入，逐项核对 PR CI 与合并后 `main` CI。已有 4A–4G 合成完成和 4H 合成回滚证据保留，不因本 ADR 变成真实模型证据。
3. 获得单独授权后，在隔离本地 Project 用合成数据从 Web 显式请求解释和摘要，完成官方模型、校验、引用展示、不可变版本、Token/延迟/费用和审计闭环；核对供应商用量，不以随机自然语言逐字一致作为成功条件。
4. 对最终发布候选验证关闭 Project/部署出口、Web 入口、应用回滚和恢复，保留迁移与历史结果；测试 Agent 成功/失败前后门禁和退出码不变。数据库灾备恢复及生产负载仍不属于这次个人版阶段退出证明。
5. 固定兼容版本/摘要，发布个人自用版制品并创建唯一 Docs 阶段报告，明确个人/合成真实验收范围、未验证项及延期企业关卡。报告 PR 合并且 Docs `main` CI 成功、所有退出证据齐全后，才能关闭 #43、4H 和阶段总 Issue 并核对 Project #2；随后才启动阶段 5 功能开发。

## 备选方案

- 继续等待企业级账户材料：企业/客户范围保留此方案，不再作为个人版退出的必需前置条件。
- 仅关闭合成阶段并延期真实集成：本次不选择，个人版仍必须完成真实适配器及获批合成真实调用验收。
- 直接填入 Key、删除安全测试或把公开政策记为零保留证明：拒绝；既没有真实集成证据，也破坏安全与事实边界。

## 正面影响

个人版可以形成真实、可追溯、可回滚的交付，不再以供应商企业承诺阻塞全部后续开发；企业接入条件仍可独立追踪。

## 负面影响与风险

供应商保留、训练、地区及下游处理存在未核实风险，不能仅靠客户端消除。所有者必须只发送允许的非敏感材料并可随时撤销启用；将个人模式用于客户数据、公开服务或扩大工具权限需要重新评审。模型/协议/价格变化仍可能暂停真实调用。

## 验证方式

- 范围确认、Docs 合并、装入 Key或单独打开 Web 任一项均不能自动触发真实请求；部署/Project 任一关闭、启用记录缺失/过期/撤销或授权范围不符时网络请求为零。
- 假 HTTP 检查唯一目标、字段 allowlist、Secret/正文脱敏、无工具/会话/重试；复用 4G 的注入、越权、幂等、超时、恢复、并发额度及校验回归，不能降低断言。
- 获批合成真实验收验证模型/用量、解释和摘要、真实 Evidence/文档版本引用、费用/traceId；失败明确且不展示原始输出，不改变扫描与门禁。
- 发布/报告不声称零保留、账户级供应商审批、客户数据或生产验收通过；延期严格边界必须在报告中可导航。

## 何时重新评估

数据、使用者、部署或公开访问范围扩大，接入企业/客户资料，供应商条款/模型/价格/协议改变，Secret/网络措施失效，或需要工具、自动重试、更高 Token/额度时，先关闭出口再重新评审。进入阶段 5 不自动扩大个人模式或真实模型外发范围。
