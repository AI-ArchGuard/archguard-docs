# ADR-0013：个人部署的只写模型凭据管理

- 状态：Accepted；项目所有者明确要求 Web 添加/删除 Key，并确认后端加密持久化；仅批准开发边界，不批准真实调用或费用
- 日期：2026-10-06
- 决策者：ArchGuard 项目所有者
- 部分替代：[ADR-0010](0010-agent-trust-boundary-and-model-egress.md)和 [ADR-0012](0012-personal-deepseek-release-scope.md)中仅运行时人工注入、禁止前端输入的凭据入口限制；其他信任边界和 [ADR-0011](0011-deepseek-official-api-egress.md)的固定官方协议、调用审批和费用限制不变

## 背景

个人部署目前没有 Web 凭据管理。所有者希望添加、替换和删除 DeepSeek 官方 API Key，并让配置在后端重启后保留。浏览器直接调用模型或把 Key 写入前端存储会绕过权限/额度边界；把明文放入业务表、Git 或聊天也不适合作为凭据托管。

本次不使用聊天中已暴露的 Key。所有者应先在 DeepSeek 官方账户撤销并生成新 Key，随后只在受控凭据入口输入，不贴到聊天、Issue、PR 或日志。

## 决策

### 范围与身份

- 仅适用于所有者控制的个人部署，单个固定 DeepSeek 凭据槽位；不实现多人自带 Key、客户账户、任意提供方或 URL，也不提前启用 Gateway/Evals。
- 管理功能默认关闭，独立于 Agent 调用开关。只有部署配置的个人所有者 OIDC 身份能读取状态、写入/替换或删除；Project Maintainer 身份本身不能管理部署级 Key。后端检查不能依赖 Web 展示或自报 actor 头。
- 对不可信 Origin、未认证、非所有者、缺少安全传输、主密钥/存储配置不合法的请求失败关闭。Web 仅同源访问 Platform，不设置跨站凭据接口；远程须 HTTPS。仅明确的本机开发 profile 可允许环回 HTTP，不允许把浏览器输入 Key 的接口公开到公网。

### 浏览器与后端存储

- Web 提供密码输入框及添加/替换、删除操作。Key 必然短暂存在输入控件、JavaScript 内存及写入请求中，不能宣称从不进入浏览器；不得放入 localStorage/sessionStorage、URL、缓存、遥测、日志或错误正文。提交后（成功或失败）、登出及离开页面清空输入，不支持回显或复制已保存 Key。
- 读取接口只返回配置状态与非敏感版本/更新时间；写入/删除响应无 Key。接口与页面使用 no-store。错误只返回稳定类别/traceId，不带原请求、验证 rejectedValue 或供应商原文。
- 后端在专用受控目录使用 AES-256-GCM 加密持久化，随机 nonce 和带部署/提供方/格式版本的 AAD；不放入业务表。独立 256 位主密钥从运行时 Secret 文件注入，绝不与密文、Git、备份说明或浏览器一起保存。只复用 JDK 加密能力，不增加云 Secret 服务或模型 SDK。
- 配置与目录须由所有者托管并限制访问；主密钥缺失、错误或密文认证失败时不回退明文，不自动重置或删除。使用有界文件读取、原子替换、同步并发和固定文件名，拒绝任意路径/符号链接；异常及审计无 Key、主密钥、密文或路径正文。
- 加密不是对被攻陷后端的防护。主密钥与密文一起泄漏仍可解密；主密钥丢失意味着重新输入新 Key。首版不承诺自动主密钥轮换或备份恢复，操作流程须明确，不能把明文备份当作恢复方案。

### 写入、替换与删除语义

- 添加/替换生成新的凭据版本，不自动测试有效性，不查询余额，不发起模型请求，也不自动启用部署/Project。只有满足 ADR-0012 其余授权、额度及出口检查后，模型端口才可读取当前凭据。
- 删除移除本部署活动密文并使未来调用无凭据可用；缺少凭据时幂等返回未配置。不得回退到旧 Key、环境变量或另一文件来源。凭据变更使引用旧凭据版本的调用批准失效；后续接入时调用前再次比对版本。
- 删除不等于撤销 DeepSeek 账户 Key，不能保证擦除文件系统快照/历史备份或撤回已发送的在途请求；页面须提示用户到提供方账户撤销。历史解释和审计保留，不含凭据。
- 审计记录操作者、写入/替换/删除动作、结果、非敏感版本和 traceId；不保存 Key 指纹/末尾字符以外发或替代权限，本版连末尾字符也不展示。

## 实施与验收

先由 Docs 冻结本决策并通过 PR/main CI，再由 Platform 交付只写 API/严格 DTO/加密存储及离线测试，Platform main CI 成功后 Web 消费固定 OpenAPI，最后 Deploy 挂载受控目录和独立主密钥。不能把凭据 UI 完成写成真实 Agent 接入、验收或阶段发布完成。

合成测试覆盖：默认关闭、非所有者拒绝、Origin/传输约束、Key 不回显/不入浏览器存储/日志、密文不含明文、重启读取、错误主密钥/篡改失败、替换/删除/并发、缺少主密钥不降级、密钥管理不触发模型、删除不影响历史 Finding/门禁。CI 只用临时合成 Key/主密钥，不使用真实 Key。真实解释/摘要仍需单独确认合成批次、请求次数和费用上限。

回滚先关闭凭据 UI 和管理接口、Project/部署出口，再退应用；保留加密存储/主密钥和历史记录，不让旧版本自动读取托管 Key。不修改 Scanner Schema 或已发布迁移。阶段 4 退出仍受 ADR-0012，企业/公网/多人场景须新评审。

## 备选与风险

- 只在后端内存保存：减少磁盘管理，但重启丢失；所有者本次选择加密持久化。
- 浏览器持久化或直连 DeepSeek：拒绝，扩大凭据暴露并绕过后台防护。
- 明文存储、默认共享管理员身份或保存聊天 Key：拒绝。
- 本地服务器、浏览器扩展/XSS、运行环境和主密钥管理仍是风险；UI 和加密本身不能证明企业合规或阻止已泄漏 Key 的外部使用。

## 何时重新评审

多人/客户/公网访问、用户自带供应商、自动有效性测试、跨部署共享、主密钥自动轮换、备份恢复或工具权限扩展时，先关闭管理与出口并另行评审。
