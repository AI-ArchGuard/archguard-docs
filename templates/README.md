# Templates

模板只定义最低内容，不代表需要为每个任务创建文档。

- [Feature Spec](feature-spec.md)：阶段能力正式进入设计时使用。
- [Technical Design](technical-design.md)：放在对应生产者仓库的 `docs/technical-design/`。
- [ADR](adr.md)：长期、跨边界或代价较高的决策使用。
- [Pull Request](pull-request.md)：实现和文档变更的评审入口。
- [Postmortem](postmortem.md)：发生需要正式复盘的事故后使用。

是否创建文档先遵循[文档编写规范](../development/documentation-standard.md)和[文档交付计划](../development/documentation-delivery-plan.md)。
